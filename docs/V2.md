# v2 model and input notes

## Model

Each of Fdewet, PC1, PC2 and PC3 is an average of three selected models trained
on 600 proteins. The broader training dataset contains 1000 proteins with three
restrained explicit-water replicas each. Development used 500 fitting and 100
tuning proteins before the selected 600-protein refits. This is not a claim of
an independent 1000-protein evaluation.

Inputs describe amino-acid identity, histidine charge, exposure, backbone and
side-chain geometry, cavities, angular packing capacity, and local chemical
fields. An edge-gated message-passing network combines these with learned atom
features near candidate solvent positions. All four outputs share extraction.

PC fitting targets used fitting-only 2nd/98th-percentile winsorization; numerical
predictions are not clipped. Development results were repeatedly used for model
selection. Publication evaluation and its cohort/history statement remain
separate review items; do not call development scores independent test results.

The `--parts` decomposition is additive. “Intrinsic” already includes local
structural information, not just amino-acid chemistry. It is not an isolated
transfer free energy. Intrinsic + context equals total, up to rounding; PC
offsets belong to the intrinsic term. These models are not force fields.

## Python

```python
from FastHydroMap.v2 import Predictor

model = Predictor()  # all four outputs; load once and reuse
table = model.predict("prepared.pdb", histidine_states={"A:42": "HIP"})
table.to_csv("maps.csv", index=False)
```

Use `Predictor(quantities=["Fdewet"], threads=4)` for one output. Calls temporarily
set PyTorch's process-wide thread count and restore it afterward; avoid concurrent
calls from threads that change this setting independently.

## Histidines

Ordinary HIS defaults to HIE with a warning. HID/HIE/HIP residue names specify
their states. An assignment CSV overrides these names:

```csv
res_uid,histidine_state
A:42,HIP
B:17A,HID
```

```bash
fasthydromap predict prepared.pdb --model v2 --histidine-states states.csv -o maps
```

Unlisted HIS retains a named state or defaults to HIE. Unknown residue IDs,
duplicate CSV IDs, and unsupported states are errors. HID/HIE are neutral
tautomers; HIP is positively charged. No pKa estimation or conformational
relaxation is performed after assigning a state.

## Inputs and preparation

Residue IDs retain chain, number and insertion code (`B:17A`); a blank chain is
`_`. Duplicate normalized IDs are rejected. Use one PDB model per call.
Resolve alternate atom locations before prediction, or use `--prepare`.
The preview rejects ambiguous alternate-location inputs rather than allowing
the SASA and chemical feature readers to select different atoms.

The Python predictor requires complete standard heavy-atom templates. CLI
`--prepare` adds missing atoms with PDBFixer and a fixed seed, without inventing
missing sequence residues. It removes heterogens and writes the prepared PDB;
inspect rebuilt regions and residue identities. Nonstandard chemistry is not
silently converted. Hydrogens are not features. Ligand, water and membrane
context is not modeled.

Provide the intended assembly yourself; FastHydroMap does not construct a
biological assembly or infer its physiological oligomeric state. Whole molecules
are required: periodic-boundary wrapping is not repaired.

The trajectory preview streams frames using topology residue IDs, but serializes
coordinates at PDB's 0.001 Å precision. This can affect grid features. Atom order
must match the topology; alternate-location ambiguity should be removed first.
Precision handling and broader trajectory validation remain release-review items.

## Assemblies and limitations

Each chain provides its solvent-grid reference while nearby chains share atom
and message-passing context. Whole chains separated beyond an 18 Å feature-support
rule are processed independently. This threshold is not a definition of binding.

Chain-order and disconnected-object checks pass, but matched assembly MD
validation remains pending. Do not claim validated assembly accuracy.

Hard cavity/grid boundaries can amplify tiny coordinate changes. The research
audit found a nearly buried residue switching from zero free grid sites to one
after rotation plus PDB rounding. Smooth-probe pilots were excluded because
they worsened low-water accuracy. The release wrapper does not remove this issue.

Training principally covers nonterminal residues with mean water count >7;
Fdewet also used the established label-range filter. Inference does not know
the true water count. Output terminal flags are helpful, not a complete
applicability classifier. Treat buried and strongly buried-interface sites
cautiously. No trained uncertainty/replica-variance predictor is included.

## Provenance

`weights/v2/manifest.json` contains all twelve checkpoint SHA-256 hashes and
fitting-only normalization. Loading verifies hashes and uses tensor-only PyTorch
checkpoint loading. No research imports, PyTorch Geometric, external XML files,
or downloads are required.

The bundled chemistry table contains numerical heavy-atom parameters derived
from HydroMap's `a99SBdisp_openmm.xml` (source hash in the manifest), including
hydrogen charges lumped onto bonded heavy atoms. These are approximate structural
descriptors, not explicit-hydrogen electrostatic energies. See
[HydroMap](https://github.com/samlobe/HydroMap) for the simulation workflow.

The regression fixture is prepared chain A of PDB 5O3L biological assembly 1.
Expected outputs come from the selected research runtime, not independent labels.
